アップロード方法（GitHub Desktop）
- 同名のフォルダー内にあるサイトのファイル・images フォルダーを含め、既存の
  ローカルリポジトリー「iwami-arts-project」に上書きコピーします。
- GitHub Desktop で Changes を確認し、Summary に「番組放送開始とプロフィール・引用注釈更新」と入力します。
- Commit to main → Push origin の順に操作します。
- GitHub Pages が反映された後に公開サイトを確認してください。
- 変更したファイルだけを上書きする場合は、別途「差分更新.zip」を使用できます。
