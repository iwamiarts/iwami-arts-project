【GitHub Desktopでの更新】
 1. ZIPを展開する。
 2. GitHub Desktop の Show in Finder で既存のリポジトリフォルダを開く。
 3. ZIPの「中身」をすべてリポジトリフォルダにコピーして、同名ファイルは上書きする。※ZIPファイルや一番外のフォルダそのものをコピーしない。
 4. GitHub Desktopで Changes を確認、Summaryに「Add Tatsunoko-kun character page」と入力して Commit to main。
 5. Push origin を押す。数分後に https://iwamiarts.jp/character.html を確認する。
