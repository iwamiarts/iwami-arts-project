【差分更新ZIPの場合】
1. ダウンロードしたZIPを解凍します。
2. GitHub Desktopで iwami-arts-project を選び、Fetch originを行い、Pull originが出たら実行します。
3. Show in Finder を押して、リポジトリのフォルダを開きます。
4. 解凍した index.html / works.html / styles.css をリポジトリ直下に上書きコピーします。
5. 解凍した images フォルダの中の .webp 写真を、リポジトリの images フォルダに追加します。画像フォルダ全体を置き換えないでください。
6. GitHub Desktopで変更を確認後、Summaryを記入して Commit to main → Push origin を実行します。
7. https://iwamiarts.jp/#international と https://iwamiarts.jp/works.html で反映を確認します。
