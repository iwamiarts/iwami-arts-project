【GitHub Desktopに反映する方法】
1. このZIPを解凍する。
2. GitHub Desktop > Show in Finder で iwami-arts-project フォルダを開く。
3. 解凍フォルダの「中身」をすべてコピーして上書き（.git フォルダはそのまま）。
4. GitHub Desktopで変更を確認し、Summaryに「『若草物語』舞台写真を追加」と入力。
5. Commit to main → Push origin。
6. 公開URL https://iwamiarts.github.io/iwami-arts-project/ を確認。
